# MicroAI-BTM-1.1.5-Nova
MicroAI BTM 1.1.5 Nova

A lightweight, browser-based experimental AI chatbot.

MicroAI is an experimental chatbot designed to explore how a small conversational system can work without relying on a cloud-based language model.

It combines statistical text generation, training-based sentence matching, lightweight intent detection, and customizable training data.

---

About the Project

MicroAI is a browser-based conversational AI experiment built around BTM (Browser-Trainable Model).

The project explores a lightweight approach to chatbot development by combining statistical language techniques with rule-based processing.

Instead of using a large neural network or an external AI service, MicroAI uses locally processed training data and text patterns to generate responses.

Features

- Statistical Text Generation: Generates text using learned word-transition patterns.
- Sentence Matching: Compares user messages with previously trained sentences to find relevant responses.
- Intent Detection: Uses lightweight rules and phrase matching to identify user intentions.
- Custom Training Data: Allows the chatbot to learn from additional sentences.
- Conversation History: Keeps conversation data in the browser.
- Local Storage: Saves supported settings and data using the browser's local storage.
- Multilingual Support: Includes language-related features for multiple languages.
- Customizable Interface: Offers interface settings and themes.

How Does It Work?

MicroAI uses several lightweight techniques:

1. Training: Processes training sentences and builds word-transition statistics.
2. Text Generation: Uses learned word patterns to generate new text.
3. Sentence Matching: Compares incoming messages with existing sentences.
4. Intent Detection: Uses predefined phrases and rules to recognize possible intentions.
5. Response Generation: Combines these mechanisms to produce a response.

Installation and Usage

The project is designed to run in a web browser.

1. Download or clone this repository.
2. Open the main HTML source in a suitable code editor.
3. Make sure "styles.css" is in the correct location.
4. Save or open the main source as an HTML document.
5. Run the project in a compatible browser.

Note: The main source file currently contains HTML and JavaScript together. Its repository filename may need to be changed to "index.html" for standard GitHub Pages deployment.

Privacy and Data

MicroAI uses browser-based storage for supported data, such as settings and conversations.

Data stored in browser Local Storage is generally specific to the browser and device being used. Clearing browser data may remove it.

Limitations

MicroAI is an experimental lightweight chatbot, not a large language model (LLM).

- It does not have the general reasoning capabilities of advanced language models.
- Its generated responses depend on its training data and learned word patterns.
- Intent detection relies on predefined rules and phrases.
- Generated text may sometimes be incomplete or irrelevant.
